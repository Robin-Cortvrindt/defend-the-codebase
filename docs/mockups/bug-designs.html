Enemy designs

Every enemy gets its own look. Each keeps its ring colour as the main colour, so you can still tell at a glance which developer counters it (grey = nobody). Each board shows today's look and two options walking along the new code-on-a-circuit lane, at their real relative size and speed. The merge conflict splits halfway, and the memory leak grows as it walks.

Typo bug · blue · React

Typo

Tiny, fast, comes in swarms

A. Squiggle wormMy pick: the wavy "spelling mistake" underline, crawling like a worm. Everyone knows that squiggle, and it still reads at this tiny size.

B. Wrong letter: a little letter tile on legs that keeps flipping between wrong letters (q, x, z…). Fun, but the letter is hard to read when it's this small.

Null pointer · orange · Java

Null pointer

Medium, the main crowd

A. Null beetleMy pick: a proper beetle with an orange shell split down the middle and the ∅ null sign on its back. Clear and bug-like.

B. Dangling pointer: a see-through, dashed "ghost" bug with an arrow pointing at an empty box in front of it: a pointer to nothing. Clever, but harder to see in a crowd.

Legacy bug · fuchsia · .NET

Legacy

Big, slow, tough

A. Floppy disk beetleMy pick: its shell is a floppy disk (the old save icon), and it kicks up dust as it trudges along. Instantly says "old tech".

B. Mainframe crawler: a beige old computer box with spinning tape reels and blinking lights, with a cobweb on it. Even more "legacy", but busier.

Merge conflict · grey · no counter

Merge conflict

Splits into "ours" and "theirs" when squashed

A. Diff bugMy pick: one bug split down the middle along a zigzag seam: a green + half and a red − half, like a code diff. When squashed it tears along the seam into a + half and a − half.

B. Two glued bugs: two small bugs, one with < and one with >, stuck together and wobbling as they pull different ways. When squashed they come apart.

Memory leak · grey · no counter

Memory leak

Grows bigger and tougher the longer it lives

A. Leaking blobMy pick: a wobbly, see-through blob that leaves a trail of drips behind it and swells as it grows. The trail makes the "leak" obvious.

B. RAM stick: a memory module on legs (gold contacts as feet) whose chips light up one by one as it fills up. Very "IT", and shows how full it is, but it's less of a bug.

Security risk · red · boss

Security risk

Boss at the end of every sprint

A. Armoured beetle, open lockMy pick: a big dark-red armoured beetle with an unlocked padlock on its back and a pulsing red alarm ring. Clearly the boss.

B. Trojan horse: a wooden horse on wheels with a red glow, the classic security threat. Funny and memorable, but it breaks from the bug look of the others.

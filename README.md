# Defend the Codebase

A browser tower defense game for the Intent Engineering Bootcamp hackathon. Bugs crawl toward production, React, Java and .NET developers squash them, and Thomas, Jeroen, Bart and Claude lend a hand.

**Play:** https://robin-cortvrindt.github.io/defend-the-codebase/

## Run locally

ES modules don't load from `file://`, so serve the folder:

```
python -m http.server 8000
```

Then open http://localhost:8000.
